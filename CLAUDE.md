The entire repository is `README.md`. It contains:

## Conventions

- Use plain GitHub Flavored Markdown; no HTML tags.
- The `What I work with` section is a fenced ` ```text ``` ` block with left-aligned columns using `·` as a separator.
- The `Projects` table uses two columns: `Project` (linked name) and `What it does` (one-line description).
- Tone is first-person, direct, and professional — no hype language.
- Keep entries in the skills block grouped by category (Networking, Systems, Video Systems, Monitoring, Automation, Frontend, Operations, Security).
